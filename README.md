# hallicivelek.com — blobs and the blob-pond

**To update the site:** run `python3 build.py`, then open `dist/custom-html.html`, select all, copy,
and paste it over everything in Cargo's Custom HTML.

**To try the pond on its own:** open `src/pond.html` in a browser.

**To check nothing broke:** `python3 tests/test_site.py` (needs Playwright, see CLAUDE.md).

Everything Claude Code needs to know is in `CLAUDE.md`.
